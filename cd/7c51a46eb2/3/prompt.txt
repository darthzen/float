## 1. The mechanism

**Scale is not the discriminator. Code state is — and the file mtimes lie about it.**

The punched black cores are produced by the **coverage intersection** at `upscale/science_render.py:254-262`, not by the NaN→zero mapping at line 247 alone:

```python
247:  out[filt] = np.where(cnt &gt; 0, acc / cnt, 0.0).astype(np.float32)   # per-filter zero
248:  cov = cnt &gt; 0
249:  common = cov if common is None else (common &amp; cov)
...
258:  if common is not None and not common.all():
261:      for filt in out:
262:          out[filt] = np.where(common, out[filt], 0.0)               # ALL filters zeroed
```

Saturated star cores are non-finite in only *some* filters. Measured from the FITS at these sites: `clear-f200w`, `clear-f335m`, `clear-f444w` are NaN at the core; `clear-f090w`, `clear-f187n` (the reference grid) and `f444w-f470n` are usually finite.

- **Without** line 262, a NaN filter contributes 0 through line 247, and `mix()` still divides by the full weight sum (`science_render.py:322-324`), so the affected channel collapses while the others stay bright → the core renders as a **saturated colour blotch**.
- **With** line 262, one NaN filter zeroes *all six*, so R=G=B=0 → the core renders as a **black hole**.

The intersection landed between 15:43 and 15:52 (it was added to fix the HST blue wedge). Both s1 renders and every s4 render predate it. The 16:09 s1 file's *mtime* postdates the edit, but a full-res run takes ~25 min, so the process loaded the source before the edit. This is independently confirmed by the filenames: neither s1 file carries the `wb` tag (`science_render.py:756`), which was in output names by 15:50:55.

Secondary point, verified and negative: I tested the hypothesis that reprojection changes the mask. It does not. `same` at `science_render.py:232-238` is False at every scale&gt;1 for this dataset (`ny*scale = 8584 ≠ 8583`), so the documented `data[::scale, ::scale]` decimation path is effectively dead code and *every* filter goes through `reproject_interp` at scale&gt;1; only at scale 1 does the reference filter take the identity path.
